# Task 2.0

## Context

У нас є команда "Cut intercalated structure cell", яка вирізає комірку по X та Y координатах. Ідея такої комірки в тому, щоб отримати мінімальну за розміром комірку, яка шляхом паралельних перенесень дозволяє побудувати всю структуру.

Нам треба також сюди додати 2 речі:

1. Логіку обрізання по Z координаті,
2. Створення файлу `cell_params.txt`.

Як приклад результату: файли в `data/projects/intercalation_and_sorption/ar/result_data/C2-7_h3/cell_ABAB` (я вручну обрізав комірку по висоті і створив файл `cell_params.txt`).

## Логіка обрізання по Z координаті

Ми повинні знайти мінімальну кількість шарів атомів вуглецю та аргону таким чином, щоб трансляцією вгору вони співпали з усіма наступними шарами. Важливо, що ми беремо для трансляції одразу і інтеркальовані атоми, і вуглець. Як приклад результату: файли в `data/projects/intercalation_and_sorption/ar/result_data/C2-7_h3/cell_ABAB`. Там в `C2-7_h3_cell_carbon_.dat` та `C2-7_h3_cell_intercalated_.dat` комірки обрізані по висоті коректно: транслюючи комбінацію атомів вуглецю та аргону, ми отримуємо всю структуру. Але структури, яка вже побудована не завжди може вистачати, приклад - `data/projects/intercalation_and_sorption/ar/result_data/C0-7_h3/cell_ABC`, там комірка має висоту значно більшу за існуючі в `init_data` структури через те, що комбінація атомів вуглецю та аргону повторюється за значно вищої висоти елементарної комірки.

Перевір приклади з існуючими комірками для `A1`, `C0`, `C2`, на цих прикладах тобі треба впевнитись, що ти вірно зрозумів логіку розрахунку висоти комірки і як саме повинна утворюватись комірка по результату "Cut intercalated structure cell". Ці ж структури можеш взяти для тестів. Якщо бачиш якісь протиріччя чи помилки там, або не розумієш однозначно логіку - задавай питання.

## Створення файлу `cell_params.txt`

Цей файл містить параметри комірки та вектори трансляції. Параметри означають на яку відстань ми повинні транслювати структури, щоб вони співпадали з шарами. Basis утворено векторами до певних точок у комірці, їх можна побудувати так:

1. Беремо точку (0,0) - назвемо її `P1`
2. В проєкції на xOY каналу, який містить точку (0,0) знаходимо координати вершини з найбільшим Y (наприклад, в структурі `A1-7_h3` це (3.993, 2.305, 0)), назвемо її `P2`
3. Знаходимо вектор `P1P2` (для структури `A1-7_h3` це буде вектор з координами (3.993, 2.305, 0)) - це буде перший вектор базису `a`
4. Беремо вектор `P1P2` з протилежним знаком X - це буде другий вектор базису `b`
5. Будуємо вектор з координатами (0,0,z), де z=c (переметру трансляції) - це буде третій вектор базису `c`

Перевір самостійсно, що за такою логікою побудовано базисні вектори в інших структурах.

Зверни увагу, що ці файли можуть бути трохи різними для різних типів структур, зокрема, в структурах типу `B*` ще задано `α=β=90` (це можна завжди вважати за істину), і кут `γ`, який визначається так:

1. Назвемо гексагон, який утворено проєкцією каналу на xOy як ABCDEF, кут ABC назвемо `α` (не плутати з `α` вище, яке ми захардкодили), сторони `AF=BC=CD=EF=a`, `AB=ED=b` (наприклад, для структури `B1` це буде α=125.3 градуси, a=5.86, b=3.07).
2. Тоді
   $$\angle BFD = 2 \arctan\left(\frac{a \sin\alpha}{b - a \cos\alpha}\right)$$
3. `γ` = 180- $$\angle BFD
(перевір, що для `B1` так ми отримаємо 106.87, як зазначено в `data/projects/intercalation_and_sorption/ar/result_data/B1-7_h7/cell_ABAB_v2_NV/cell_params_.txt`)

Продивись загалом ці файли для `A*`, `B*` та `C*`, визнач логіку, за якою побудовані ці файли і напиши код, яка дозволяє будувати аналогічні параметри відповідно. Цей файл також повинен створюватись при натисканні на "Cut intercalated structure cell".

Але: якщо вже така папка існує, то треба не перезаписувати файли, а створити нову папку з назвою `cell_{type}_v{i}_j` (наприклад, якщо `cell_ABAB_v3` існує, то створити `cell_ABAB_v3_1`).
